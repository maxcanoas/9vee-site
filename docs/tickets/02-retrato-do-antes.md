# 02: Retrato do antes

**O que construir:** o registro do site atual para o relatório de entrega com o antes e o depois, que a proposta promete. Ele precisa existir antes de o Wix sair do ar.

**Depende de:** nenhum (pode começar já).

**Horas:** 0,5. **Semana:** 1 ou 2.

**Situação:** ready-for-agent

- [ ] Lighthouse mobile das páginas principais do Wix (home, cursos, tradução, treinamentos, LMS e quem somos): Performance, Acessibilidade, Boas práticas, SEO, LCP e CLS.
- [ ] As rodadas contam como visita no GA4 do site atual: o documento anota o dia, para descontar depois.
- [ ] Os números do inventário, com data: sessões, visitantes, origem, envios de formulário e Search Console.
- [ ] O que o site atual não tem, para o antes e o depois: aviso de cookies, conversões no GA4, página de NR-1, páginas de idioma, títulos próprios.
- [ ] Tudo num documento em `docs/`, versionado.
