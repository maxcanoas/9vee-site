# 18: Imagem de compartilhamento por página

**O que construir:** cada página ganha a própria imagem de prévia, para o link mostrar o título certo quando alguém compartilhar no WhatsApp ou nas redes.

**Depende de:** 17 (títulos finais).

**Horas:** 1,5. **Semana:** 8.

**Situação:** ready-for-agent

- [ ] Um script gera uma imagem de 1200 × 630 por página, com o título sobre a arte da marca.
- [ ] Cada página aponta para a própria imagem no Open Graph; o teste do HTML gerado confere.
- [ ] Prévia conferida no WhatsApp, com o preview publicado.
